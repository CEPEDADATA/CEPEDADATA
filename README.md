### 💡 Proyectos Destacados

```
📁 DATA-AND-AUTOMATION-PORTFOLIO
├── 🔄 n8n-HubSpot-Salesforce-Sync/      # Pipeline automatizado de reconciliación y enriquecimiento de datos CRM
├── 📈 Telecom-Customer-Churn-Analysis/  # Modelado predictivo de fuga y valor de vida de clientes (LTV)
├── 🕷️ ETL-MultiSource-WebScraping/      # Extracción automatizada, parsing con regex y carga en PostgreSQL
├── 📊 Executive-BI-Dashboard-Engine/    # Modelado dimensional en estrella, métricas DAX e indicadores clave
└── 🧠 Anomaly-Detection-Financial/      # Algoritmos de clustering espacial y Z-Score para control de fraude
```

| Proyecto | Descripción | Tecnologías |
| :--- | :--- | :--- |
| **🔄 Sincronización n8n HubSpot ↔ Salesforce** | Automatización programada para buscar empresas huérfanas en HubSpot, consultar Salesforce por NIT mediante API REST, conciliar datos y actualizar en lote (*Split in Batches*). | `n8n`, `JavaScript`, `HubSpot API`, `Salesforce API`, `Regex` |
| **📈 Análisis Predictivo Telecom** | Modelo de clasificación para predecir churn en clientes B2B/B2C, identificando factores de riesgo y optimizando la retención comercial. | `Python`, `Scikit-Learn`, `Pandas`, `XGBoost`, `Power BI` |
| **🕷️ Scraping & Pipeline ETL** | Extracción web resiliente con control de proxies, limpieza estructurada de datos no formateados y persistencia en base de datos relacional. | `Python`, `Selenium`, `BeautifulSoup4`, `PostgreSQL`, `SQLAlchemy` |
| **📊 Tableros de Control Ejecutivo** | Diseño de modelos analíticos en estrella con segmentación de clientes, forecasting de ventas e indicadores financieros en tiempo real. | `Power BI`, `DAX`, `SQL Server`, `Excel Avanzado` |
